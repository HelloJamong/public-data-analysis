# 음주운전 데이터 분석 프로젝트

AI와데이터기초 과제용 - 공공데이터를 활용한 음주운전 통계 분석

## 📊 프로젝트 개요

경찰청에서 제공하는 2024년 음주운전 적발 데이터(116,052건)를 분석하여 지역별, 나이대별 음주운전 현황을 시각화하는 프로젝트입니다.

## 📁 프로젝트 구조

```
public-data-analysis/
├── analyze_drunk_driving.py    # 메인 분석 스크립트
├── data/
│   └── 경찰청_음주운전_20241231.csv
├── .gitignore
└── README.md
```

## 🔍 분석 내용

### 1. 데이터 전처리
- 경찰서명을 기반으로 17개 광역자치단체 분류
- 시/군 단위 경찰서를 소속 광역자치단체로 자동 매핑
- 나이를 10대 단위로 그룹화 (10대~70대 이상)

### 2. 주요 분석 결과

**지역별 적발 건수 TOP 5**
1. 경기도: 32,283건 (27.8%)
2. 서울특별시: 12,299건 (10.6%)
3. 경상남도: 8,031건 (6.9%)
4. 충청남도: 7,512건 (6.5%)
5. 경상북도: 7,076건 (6.1%)

**나이대별 적발 건수**
- 40대: 29,390건 (가장 많음)
- 30대: 27,149건
- 50대: 25,028건
- 20대: 18,020건
- 60대: 12,887건

**지역-나이대 조합 TOP 3**
1. 경기도 40대: 8,607건
2. 경기도 30대: 8,328건
3. 경기도 50대: 6,548건

## 🚀 실행 방법

### 방법 1: 로컬 환경에서 실행

#### 필요한 라이브러리 설치
```bash
pip install pandas matplotlib seaborn numpy
```

#### 스크립트 실행
```bash
python analyze_drunk_driving.py
```

### 방법 2: 구글 Colab에서 실행 [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/)

1. **Colab 파일 사용**
   - `analyze_drunk_driving_colab.py` 파일을 Colab에 업로드
   - 또는 GitHub에서 직접 열기

2. **데이터 파일 준비**
   - 스크립트 실행 시 파일 업로드 창이 나타남
   - `경찰청_음주운전_20241231.csv` 파일 선택하여 업로드

3. **실행**
   - 모든 셀을 순서대로 실행
   - 시각화가 Colab 노트북에 바로 표시됨
   - 원하는 경우 생성된 이미지를 다운로드 가능

#### Colab 버전의 주요 차이점
- **한글 폰트**: 맑은 고딕 대신 나눔고딕 자동 설치
- **파일 업로드**: `files.upload()` 사용하여 대화형 업로드
- **시각화 표시**: `plt.show()`로 노트북에 바로 표시
- **파일 다운로드**: `files.download()`로 이미지 다운로드 가능

## 💡 주요 기능

### 지능형 지역 분류
- 266개의 모든 경찰서를 17개 광역자치단체로 100% 정확하게 분류
- 특별시/광역시, 도 경찰청, 시/군 단위를 3단계로 매핑
- 딕셔너리 기반 효율적인 매칭 알고리즘

### 데이터 분석
- 지역별 통계
- 나이대별 통계
- 지역 × 나이대 크로스 분석
- TOP 10 조합 추출

### 시각화
- 고해상도 PNG 파일 생성 (300 DPI)
- 한글 폰트 지원 (맑은 고딕)
- 개별 차트로 분리하여 가독성 향상

## 📋 데이터 컬럼

- 연번: 일련번호
- 성별: 남자/여자
- 적발횟수: 음주운전 적발 횟수
- 나이: 적발 당시 나이
- 알콜농도: 혈중알콜농도
- 측정거부: Y/N
- 측정일시: 적발 일시
- 관할경찰서: 적발 경찰서명

## 🎯 프로젝트 특징

- **완전한 지역 매핑**: 기타 분류 없이 모든 데이터를 정확한 광역자치단체로 분류
- **깔끔한 코드**: UTF-8 인코딩 처리, 모듈화된 함수 구조
- **고품질 시각화**: 개별 차트로 분리하여 각 분석 결과를 명확하게 표현
- **재현 가능성**: 전체 분석 과정이 단일 스크립트로 자동화
